# Work Tools

Panel personal de herramientas para cálculos de trabajo. Funciona completamente en el navegador y no requiere backend, base de datos ni autenticación.

## Herramientas

- `/`: Cierre diario

## Desarrollo

Requiere Node.js `>=22.12.0`.

```sh
npm install
npm run dev
```

El servidor local queda disponible en `http://localhost:4321`.

## Verificación

```sh
npm test
npm run build
```

El proyecto utiliza Astro, Tailwind CSS mediante `@tailwindcss/vite` y TypeScript estricto.
